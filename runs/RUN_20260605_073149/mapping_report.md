## SECTION 1: EXECUTIVE SUMMARY
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

**Source FTL Bronze Table:** ZOOM_AI_POC.BRONZE.BRZ_FTL_AGENT_BASE_AGG  
**Target PI Silver Tables:** 10 active tables (SLV_ACCT_FIRST_ACTIVE, SLV_COMBINED_CHANNELS, SLV_CONSOLIDATED_USAGE, SLV_DAILY_METRICS, SLV_MONTHLY_METRICS, SLV_ROLL_29_DAY_USAGE, SLV_USAGE_MASTER, SLV_USER_ACTIVE_DAYS, SLV_USER_FIRST_ACTIVE, SLV_WEEKLY_METRICS)

**Migration Readiness Score:** 45/100

**Total FTL columns analyzed:** 14  
**Successfully mapped:** 8 (ACCOUNT_ID, AGENT_ID, ENGAGEMENT_ID, DIRECTION, MODALITY, CHANNEL, PHONE_SESSIONS, INBOUND_PHONE_MS)  
**Partially mapped:** 3 (DATA_DATE requires parsing, IS_ACTIVE semantic match, CLUSTER for regional mapping)  
**New capabilities (no PI equivalent):** 3 (ZCC_ACCOUNT_ID, CLIENT_TYPE, OS)  
**Gaps (PI Silver columns with no FTL source):** 17  
→ **GAP-001:** ENGAGEMENT_STATUS (PI requires engagement outcome tracking)  
→ **GAP-002:** SLA_ACHIEVED (PI requires SLA compliance tracking)  
→ **GAP-003:** WINDOW (PI requires R1/R7/R28 windowing logic)  
→ **GAP-004:** CHAT_USAGE metrics (PI tracks chat but FTL has no chat session counts)  
→ **GAP-005:** VIDEO_USAGE metrics (PI tracks video but FTL has no video session data)  
→ **GAP-006:** IS_PAID_USER (PI requires payment classification)  
→ **GAP-007:** ACTIVE_DAYS_LAST_7/ACTIVE_DAYS_LAST_28 (PI requires rolling activity windows)  
→ **GAP-008:** Historical first-active dates (FTL provides current snapshot only)  
→ **GAP-009:** User activity segmentation (ACTIVE_1_DAY_L7, ACTIVE_4_7_DAYS_L7, etc.)  
→ **GAP-010:** USERS_ACTIVE_16PLUS_DAYS (PI requires long-term activity tracking)  
→ **GAP-011:** CHAT_SESSIONS count (PI requires discrete session tracking)  
→ **GAP-012:** SLA_ACHIEVED_SESSIONS count (PI requires session-level SLA tracking)  
→ **GAP-013:** ACTIVE_USERS derived count (requires aggregation logic)  
→ **GAP-014:** SOURCE_TABLE metadata (system-generated, low priority)  
→ **GAP-015:** PRODUCT_NAME constant (system-generated, low priority)  
→ **GAP-016:** REFRESH_TIMESTAMP (system-generated, low priority)  
→ **GAP-017:** DURATION_SEC for non-phone channels (FTL only has INBOUND_PHONE_MS)  

**Blocking items:** 4 (GAP-003 windowing logic, GAP-004 chat metrics, GAP-007 rolling activity, GAP-009 activity segmentation)

**Overall Assessment:** The FTL Bronze table provides strong coverage for phone-based engagement tracking but lacks critical multi-channel analytics, activity windowing, and historical tracking capabilities that existing PI Silver tables require. Two tables (SLV_ROLL_29_DAY_USAGE and SLV_USER_ACTIVE_DAYS) are not feasible with current FTL data due to missing historical activity tracking. The remaining eight tables can be partially rebuilt with caveats, requiring supplemental data sources or business logic modifications to restore full functionality.
